## 読む順番（おすすめ）

1. [構成図 v1](02_構成図/v1_見直し反映.md) ── 全体像と、鍵・身元・判定の設計
2. [論点台帳](03_論点台帳.md) ── いま何が決まっていて、何が未決か
3. [論点解説](05_論点解説/00_概要.md) ── 未決論点を議論するための前提知識
4. 必要に応じて [90_基礎知識/](90_基礎知識/01_LiteLLM_Proxyと代替.md) へ深掘り
5. 作る段になったら [開発環境構築](01_開発環境/00_環境構築手順.md) と [Phase 0 詳細設計](04_詳細設計/00_Phase0_歩く骨格.md)
